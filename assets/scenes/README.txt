Photographs for the "When do I need a Personal Paparazzi?" section.

Nine files, one per category. Drop them in here with these exact names and the
section picks them up:

  landmarks.jpg     honeymoons.jpg    parties.jpg
  family.jpg        concerts.jpg      proposals.jpg
  graduations.jpg   birthdays.jpg     influencer.jpg

Each one: 800 x 600 pixels (4:3), JPEG. They are displayed about 340 pixels
wide, so 800 wide keeps them sharp on a good screen.

What each shot needs is written in index.html, on the frame it belongs to.

Guidelines, section 08: real output from real shoots. No studio portraits, no
white backgrounds, no obvious model casting, no heavy filters over faces. Every
recognisable face needs a signed release on file before it goes anywhere.
