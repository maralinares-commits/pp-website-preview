Sign in to edit

This editor saves straight to the website. You need a GitHub access key so it can do that. You only do this once on each computer.

  1. Open this GitHub page, signed in as an account that can edit the website.
  2. Give it a name like Personal Paparazzi content, and set it to expire when you like.
  3. Under Repository access, choose Only select repositories and pick pp-website-preview.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else.
  5. Press Generate token, copy what it gives you, and paste it below.

The key is kept in this browser only. It is never sent anywhere except GitHub, and signing out deletes it.
